03 / VERIFIED ISO FINDINGS

What the image contains

  • UDF 2.x Blu-ray image with a BDJO descriptor naming org.bdj.InitXlet.
  • BDMV/JAR/00000.jar contains the BD-J Xlet, supporting classes, metadata tables, and bonk/hen.bin.
  • The Xlet uses BD-J/TV APIs and AWT; these are not browser JavaScript APIs.
  • The embedded Hx/HEN stage is not safe to execute based on the warning in the supplied NOTICE.

The BD-J application is not itself a WebKit exploit. Browser-side JavaScript cannot replace the missing browser sandbox and kernel privilege stages.
